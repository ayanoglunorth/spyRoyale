# Güvenlik Politikası

## Desteklenen sürüm

Güvenlik düzeltmeleri yalnızca `main` dalındaki güncel sürüme uygulanır.

## Açık bildirme

Bir güvenlik açığını herkese açık issue ile paylaşmayın. Açıklama, etkilenen bileşen, yeniden üretim adımları ve olası etkiyi içeren bildirimi GitHub üzerinden depo sahibine özel olarak iletin.

Bildirim alındığında bulgu doğrulanır, etki değerlendirilir ve düzeltme takvimi bildirilir. Düzeltme yayımlanmadan önce ayrıntılar kamuya açıklanmaz.

## Kapsam

Özellikle Socket.IO olay yetkilendirmesi, girdi doğrulaması, CORS yapılandırması, bağımlılıklar ve yanlışlıkla yayımlanmış gizli bilgiler kapsam içindedir.
