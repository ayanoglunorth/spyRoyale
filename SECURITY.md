# Security Policy

## Supported version

Security fixes are applied only to the current version on the `main` branch.

## Reporting a vulnerability

Do not disclose vulnerabilities in a public issue. Send the repository owner a private report through GitHub that includes a description, affected component, reproduction steps, and potential impact.

Reports are validated, assessed for impact, and acknowledged with a remediation timeline. Details will not be disclosed publicly before a fix is available.

## Scope

Socket.IO event authorization, input validation, CORS configuration, dependencies, and accidentally published secrets are in scope.
